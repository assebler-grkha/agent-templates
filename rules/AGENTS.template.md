# Project Rules & Token Efficiency Protocol

## 1. Порядок поиска (Правило 3 уровней — строго по приоритету)
1. **Слой 1 — Граф связей (`codebase-memory-mcp`)**:
   - Шаг 0 (обязательно): `codebase-memory-mcp_list_projects` — точное имя проекта; `codebase-memory-mcp_index_status` — свежесть индекса (при расхождении — `index_repository`).
   - `codebase-memory-mcp_search_graph(pattern)` — поиск функции, класса, маршрута.
   - `codebase-memory-mcp_trace_path(symbol, direction)` — поиск вызывающих/вызываемых связей.
   - `codebase-memory-mcp_get_code_snippet(symbol)` — точечное чтение тела нужной функции/класса БЕЗ чтения всего файла.
2. **Слой 2 — Долгосрочная память (`agentdb`)**:
   - Перед сложными архитектурными задачами проверь готовые решения: `agentdb_agentdb_search(query)`.
3. **Слой 3 — Текстовый поиск (только если нет в графе/памяти)**:
   - `grep` / `glob` с обязательными фильтрами путей и расширений (исключая `node_modules`, `dist`, `.git`, `.venv`).

## 2. Запрет на «жадное» чтение файлов (No Greedy Reads)
- **ЗАПРЕЩЕНО** читать весь файл целиком, если в нем больше 100 строк или нужен только фрагмент.
- Для чтения фрагментов используй `read` с `offset`/`limit` или `codebase-memory-mcp_get_code_snippet`.
- Запрещено читать файлы сборки, логи (`*.log`), lock-файлы (`package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`).
- Запрещено повторно перечитывать один и тот же файл без изменений в рамках задачи.

## 3. Оптимизация терминала и правок
- Длинные выводы команд фильтруй через сжатие (`rtk` — внешний CLI-сжиматель вывода; если не установлен — обычный вывод через `head` / `Select-Object -First`).
- Используй компактные флаги (`git status -s`, `--quiet`, `-q`).
- Формируй и проверяй правки перед применением, избегая циклов мелких правок по 1 строке.

## 4. Минимализм и качество кода (YAGNI / Aislop)
- Не создавай вспомогательные абстракции, фабрики или утилиты «на будущее».
- Перед сдачей задачи обязателен запуск проверки качества: `aislop_aislop_scan`, при отсутствии MCP — `node ~/.agent-templates/tools/aislop/dist/cli.js scan`. Порядок: сначала scan, потом `aislop_aislop_fix`; при `MCP error -32001` — повторить на меньшем `path` или из терминала.
