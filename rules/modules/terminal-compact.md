## Оптимизация вывода терминала и команд

- **Сжатие вывода**: При наличии утилит фильтрации и сжатия (`rtk`, `head`, `tail`, `Select-Object -First`) применяй их для команд с длинным выводом.
- **Лаконичные флаги**:
  - Git: `git status -s`, `git diff --stat`, `git log -n 5 --oneline`.
  - Установщики пакетов: флаги минимизации вывода (`--quiet`, `-q`, `--no-progress`).
  - Тесты: запуск только конкретного сьюта/тест-кейса вместо всего раннера (`pytest tests/test_unit.py -k test_func`, `vitest run src/utils.test.ts`).
- **Батчинг правок**: Группируй связанные микро-правки, избегая длинных циклов «изменил 1 символ -> запустил -> упало».
