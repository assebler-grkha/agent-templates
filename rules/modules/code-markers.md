# Модуль: Маркировка технического долга, заглушек и хардкода (AGENT:*)

## 1. Обязательный стандарт маркеров
При генерации временного кода, моков или заглушек агент **ОБЯЗАН** снабжать их стандартизированным комментарием:
- `AGENT:MOCK [scope]: <описание> -> <что подключить>` — статические данные, фиктивные списки, мок-ответы.
- `AGENT:STUB [scope]: <описание> -> <что реализовать>` — пустые функции, заглушки интерфейсов, NotImplemented.
- `AGENT:HARDCODE [scope]: <описание> -> <в какую env-переменную вынести>` — зашитые локальные URL, порты, тестовые ID.
- `AGENT:TEMP [scope]: <описание>` — временные костыли и обходные пути на период отладки.

## 2. Запрет на «голые» TODO
- Запрещено оставлять в коде безымянные `// TODO:`, `// FIXME:`, `// STUB:`.
- Любая недоделанная функциональность должна быть размечена тегом `AGENT:STUB` или `AGENT:MOCK`.

## 3. Автоматический контроль через AIslop
- Глобальный гейт качества `aislop scan` распознает маркеры `AGENT:*` как задокументированный долг.
- Неразмеченные мок-переменные (`mock*`, `dummy*`), голые `TODO` или хардкод (`http://localhost`) автоматически снижают рейтинг проекта в `aislop scan` и выводят предупреждение с требованием проставить тег.

## 4. Быстрый поиск долга (Zero-Token Query)
Для поиска всех заглушек и моков в проекте использовать точечный запрос:
```bash
# Поиск всех маркеров в проекте
rg "AGENT:(MOCK|STUB|HARDCODE|TEMP)"

# Поиск только моков
rg "AGENT:MOCK"
```
Запрещено перечитывать файлы кодовой базы целиком для поиска мест, где остались заглушки.
