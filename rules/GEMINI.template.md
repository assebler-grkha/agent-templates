# Antigravity / Gemini Agent Protocol

## Приоритет поиска и навигации
1. **Первый приоритет**: `codebase-memory-mcp` — используй граф знаний для поиска связей, классов, функций и компонентов.
2. **Второй приоритет**: `agent_memory` — проверка решений и знаний в `search_memory` (по базам `agent_memory.db` и `pathfinder.db`).
3. **Третий приоритет**: прямой поиск по файлам (`grep_search`, `find_by_name`, `view_file` с диапазоном строк).

## Контроль контекста и токенов
- Никакого чтения файлов целиком без строгой необходимости (`StartLine`/`EndLine` обязательны при размере > 100 строк).
- Не читай бинарные файлы, lock-файлы (`package-lock.json`, `poetry.lock`), папки сборки и кэши.
- Сворачивай длинные листинги: используй `MaxDepth` в `find_by_name`.

## Стандарты разработки
- **YAGNI (Ponytail)**: Минималистичный подход без лишней вариативности и оверинжиниринга.
- **Чистота кода (Aislop)**: Запуск `npx aislop scan` перед коммитами.
- **Фиксация контекста**: Важные архитектурные решения сохраняй в `agent_memory` через `store_memory`.
