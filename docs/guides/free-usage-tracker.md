# Free Usage Tracker Plugin (OpenCode)

Плагин **Free Usage Tracker** дописывает в конец каждого ответа агента фактический расход токенов. Данные берутся из локальной SQLite-базы OpenCode (`opencode.db`), отчёт приклеивается детерминированно — нейросеть не тратит токены на его генерацию.

> Важно: в базе OpenCode нет таблиц лимитов (таблица `model_cost` отсутствует, `cost` на бесплатных тарифах равен 0). Поэтому плагин показывает **факты расхода**, а не проценты квоты. Пулов и «лимитов по 6-часовым окнам» больше нет — эта логика удалена как нереализуемая локально.

## Как это работает

1. Хук `experimental.text.complete` (output-side хук SDK OpenCode) получает готовый текст ответа и мутирует `output.text` по ссылке — доставка мимо контекста модели.
2. `queryStats()` читает базу в read-only режиме и считает суммы по JSON-полю `message.data`: `tokens.input/output/reasoning` у сообщений с `role = 'assistant'`. Текущее сообщение исключается из подсчёта (его в базе ещё нет) и оценивается отдельно: ~4 символа на токен.
3. Защита от дублей: один футер на `messageID` (хук может срабатывать несколько раз на сообщение — до/после вызовов инструментов) плюс проверка маркера в тексте.
4. Любая ошибка глушится (`try/catch`, тихий `return null`): ответ уходит без футера, но никогда не ломается.

## Что показывает футер

```text
---
⚡ Токены: ответ ~2 · сессия 2 · сегодня 1 778 344 (big-pickle)
```

- **ответ** — оценка текущего ответа (~4 символа/токен);
- **сессия** — сумма токенов assistant-сообщений текущей сессии + текущий ответ;
- **сегодня** — то же по всем сессиям с начала суток (местное время);
- **`$cost`** — добавляется, только если суммарная стоимость сессии > 0;
- **`(model)`** — `modelID` последнего assistant-сообщения.

## Требования

- Node 22.5+ (драйвер `node:sqlite`) либо рантайм OpenCode под bun (`bun:sqlite`). Зависимостей нет; если драйверов нет — плагин молча не ставит футер.
- База: `~/.local/share/opencode/opencode.db`, переопределяется переменной `OPENCODE_DB_PATH`.

## Установка

1. Скопируйте `plugins/opencode/free-usage-tracker.ts` в директорию плагинов OpenCode (это же делает `scripts/install.ps1`):

   ```bash
   # Windows
   %USERPROFILE%\.config\opencode\plugins\free-usage-tracker.ts

   # Linux/macOS
   ~/.config/opencode/plugins/free-usage-tracker.ts
   ```

2. Перезапустите активную сессию OpenCode или откройте новую.
3. Футер появится в конце следующего ответа агента.

## Как изменить логику

Исходник — `plugins/opencode/free-usage-tracker.ts` (экспорт по умолчанию + именованный `FreeUsageTrackerPlugin`). Точки настройки:

- `MARKER` — маркер футера (и защита от повторной вставки);
- делитель `output.text.length / 4` — грубая оценка токенов текущего ответа;
- SQL в `queryStats()` — схема: таблица `message`, колонки `id / session_id / time_created / data`, всё значимое в JSON `data` (`role`, `modelID`, `cost`, `tokens.{input,output,reasoning,cache}`);
- `dbPath()` — путь к базе и `OPENCODE_DB_PATH`.
