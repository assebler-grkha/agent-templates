# Практическое руководство по экономии токенов в AI-разработке

Данное руководство обобщает опыт оптимизации рабочих пространств (сокращение расхода токенов на 70–85% и устранение лимитов TPM/RPM).

---

## 1. Отключение избыточных глобальных MCP-серверов
- **Проблема**: Каждый подключенный MCP-сервер передает в системный промпт агента полное описание всех своих инструментов со схемами параметров (JSON-schema). При 10+ серверах это сжигает 50,000–70,000 токенов на **каждом** запросе до того, как вы напишете первое слово!
- **Решение**: Отключать неиспользуемые серверы в глобальной конфигурации. Оставлять активными только 3 ядра:
  1. `codebase-memory-mcp` (навигация по графу)
  2. `agentdb` (долгосрочная память)
  3. `aislop` (контроль качества)
- **Результат**: Базовый оверхед снижается с ~66k токенов до < 8k токенов на запрос.

---

## 2. 3-уровневый протокол поиска
Вместо чтения файлов и глобального поиска по тексту:
1. **Граф связей (`codebase-memory-mcp`)**:
   - Поиск символов через `codebase-memory-mcp_search_graph`.
   - Анализ связей через `codebase-memory-mcp_trace_path`.
   - Чтение конкретной функции через `codebase-memory-mcp_get_code_snippet` (загружает только 15-30 строк вместо файла на 500 строк).
2. **Память (`agentdb`)**:
   - Проверка прошлых решений через `agentdb_agentdb_search`. Избавляет от повторного анализа архитектуры.
3. **Текстовый `grep`/`find`**:
   - Использовать только если символа нет в графе/памяти, с обязательными фильтрами расширений (`*.ts`, `*.py`) и исключением служебных папок.

---

## 3. Протокол No Greedy Reads
- **Запрет на чтение файлов целиком**: файлы больше 100 строк нельзя читать без указания диапазона (`offset` / `limit`).
- **Блокировка lock-файлов**: `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock` содержат десятки тысяч строк и сжигают весь контекст. Их чтение агентом должно быть запрещено правилом.
- **Ограничение глубины листинга**: использовать узкие glob-паттерны и глубину 1–2 уровня при обходе каталогов.

---

## 4. Сжатие файлов инструкций (AGENTS.md / GEMINI.md)
- Файлы инструкций подгружаются агенту в контекст при каждом шаге или инициализации.
- Старые многостраничные инструкции (20–40 КБ) содержат много балласта.
- Эталонный размер рабочего файла правил: **до 3–5 КБ**.

---

## 5. Лаконичность терминала и батчинг правок
- Использовать сжатие вывода (`rtk` — внешний CLI-сжиматель; если не установлен — флаги тишины `--quiet`, `-q`, `git status -s`).
- Группировать связанные правки вместо итеративного цикла из 10 микро-исправлений.
- Проверять код перед коммитом через `aislop_aislop_scan` (fallback: `node ~/.agent-templates/tools/aislop/dist/cli.js scan`).
