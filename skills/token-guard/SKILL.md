# Token Guard (Контроль контекста)

Скилл активируется при выполнении поиска по кодовой базе, исследовании репозитория или чтении документации для поддержания минимального расхода токенов.

## Триггеры активации
- Агент собирается выполнить широкий поиск или прочитать файлы неизвестного размера.
- Пользователь просит «исследовать проект», «проверить структуру», «найти где объявлено».
- Запрос пользователя: "следи за токенами", "экономь контекст".

## Протокол контроля токенов
1. **Предварительная проверка размера**:
   - Перед вызовом инструмента чтения файла проверить размер (`find_by_name` возвращает размер файлов).
   - Если файл > 100 строк (> 5–10 КБ) — **запрещено** читать его целиком.
2. **Маршрутизация поиска**:
   - Сначала граф вызовов: `codebase-memory-mcp`.
   - Затем долговременная память: `search_memory`.
   - Только потом точечный `grep` с обязательным указанием расширения (`*.ts`, `*.py`).
3. **Фильтрация вывода**:
   - Ограничивать количество строк в результатах поиска.
   - Не запрашивать повторно файлы, которые уже читались в текущем диалоге.
