# prefs-writer

Скилл записи пользовательских предпочтений в домен `preferences` базы AgentDB. Плагин `prefs-injector` подбирает их детерминированно по тегам сценариев — этот скилл отвечает за то, чтобы записи были короткими, точными и не раздували контекст.

## Когда использовать

- Пользователь высказал предпочтение («всегда…», «никогда…», «в дизайне…») — зафиксируй его этим скиллом.
- Пользователь просит изменить/удалить ранее записанное предпочтение.
- Первое использование: предложи собрать базовый набор (по 1–2 тезиса на частые сценарии).

## Формат записи

- **Тезис ≤ 140 символов**, повелительное наклонение, без воды.
  - Хорошо: `Используй только SVG-иконки вместо эмодзи.`
  - Плохо: `Было бы здорово, если бы ты по возможности старался использовать SVG...`
- Одна запись = один тезис. Не склеивай несколько мыслей в одну.
- Язык тезиса — язык пользователя.

## Куда писать

- Инструмент: `agentdb_agentdb_store`.
- `doc_id`: `pref:{tag}:{slug}` (slug — 2–4 слова латиницей через дефис).
- `domain`: `preferences`.
- `content`: сам тезис.
- `metadata`: JSON `{"tags": ["{tag}"]}` — ровно один тег сценария на запись.
- Изменение = перезапись того же `doc_id` (update-in-place). Удаление — только по явной просьбе.

## Теги сценариев

`always`, `default`, `design`, `testing`, `architecture`, `planning`, `security`, `docs`, `debugging`, `refactor`, `performance`, `devops`.

- `always` — инжектится в каждое сообщение (только самое критичное, максимум 2–3 записи).
- `default` — когда сообщение ни к чему не привязалось (1–2 записи).
- Остальные — по теме. Бюджет на сценарий ≤ 400 символов суммарно.
- Новый тег не выдумывай: ключевые слова живут в коде плагина, неизвестный тег не сработает. Если сценария не хватает — скажи пользователю, что нужно расширить словарь в `prefs-injector.ts`.

## Запреты

- Не пиши в домен `prefs-sessions` — это журнал плагина, правится только им.
- Не дублируй тезисы под разными `doc_id` — сначала `agentdb_agentdb_search` по домену `preferences`.
- Не превышай бюджеты: при переполнении сценария предложи пользователю выбрать, что выкинуть.
