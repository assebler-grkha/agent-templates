# Название скилла

Краткое описание назначения скилла (1-2 предложения): какую конкретную задачу решает и в каких сценариях активируется.

## Триггеры активации
Укажи фразы или события, при которых агент должен активировать этот скилл:
- "запусти аудит..."
- "проверь проект..."
- `/skill-command`

## Входные данные
- Что требуется агенту для старта (путь к проекту, имя ветки, конфигурация и т.д.).

## Протокол выполнения (Шаги)
1. **Шаг 1: Подготовка/Проверка**
   - Точечное получение контекста без жадного чтения.
2. **Шаг 2: Основное действие**
   - Выполнение целевой операции (запуск скрипта, анализ, трансформация).
3. **Шаг 3: Верификация**
   - Проверка результата, валидация через тесты или `aislop scan`.
4. **Шаг 4: Отчет**
   - Компактный вывод результата без лишней воды.

## Правила экономии токенов
- Не загружать полные файлы более 100 строк.
- Использовать скрипты из папки `scripts/` вместо ручных многошаговых команд.
