## Быстрый старт (За 3 шага)

### 1. Установка зависимостей
```bash
npm install
# или
pnpm install
# или
poetry install
```

### 2. Настройка переменных окружения
Скопируйте эталонный файл конфигурации и укажите локальные параметры:
```bash
cp .env.example .env
```

### 3. Запуск в режиме разработки
```bash
npm run dev
# или
python main.py
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000).

---

## Основные команды проекта

- `npm run dev` — запуск локального dev-сервера с горячей перезагрузкой.
- `npm run build` — компиляция проекта для продакшена.
- `npm test` — запуск набора модульных тестов.
- `npx aislop scan` — аудит чистоты кода и отсутствия AI-шлака.
